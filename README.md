# Kokoro-82B-TTS-Agent-Pack-CPU
This is an FP16 Kokoro TTS (Text to Speech) 82 Billion Parameter Model that runs on CPU only using ONNX. It's been split into small enough files to upload into github web interface, and it's meant for an AI agent to be able to pull to Kokoro-82B FP16 TTS full model from github and recombine it in a local sandbox for use. CPU inference TTS AI Skill.
